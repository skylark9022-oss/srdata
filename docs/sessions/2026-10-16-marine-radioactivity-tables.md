## 요약: 이 세션에서 만든 것

| 파일 | 내용 |
|---|---|
| `srdata/pdf/report_tables.py` | 캡션·각주·[계속] 병합·병합 셀 해석·다단 머리글·각주 위첨자 제거를 하는 `extract_report_tables()` |
| `srdata/analysis/measurements.py` | 측정값 문자열 분리 `parse_measurement()`, `split_measurement_columns()` |
| `srdata/excel/writer.py` | `freeze_header`, `numeric_text`(소수 자릿수를 표시 형식으로 유지) 옵션 |
| `scripts/extract_marine_radioactivity_report.py` | 보고서 → 원문 그대로 / 분리 / 분리 보정 세 파일 생성. `MANUAL_CORRECTIONS` 로 원문 표기 오류 보정 |
| `tests/test_report_tables.py`, `tests/test_measurements.py` | 12개 테스트 |

## 원문 PDF 에서 확인한 특이사항

- 표 2.11(43쪽): 머리글 순서와 값 순서가 어긋남. 원문 그대로 추출, 목록 시트 비고에 기록.
- 표 2.15 머리글이 `조사정점-¹⁾` → 열 이름 `조사정점-`.
- 표 2.22 홍합 2행 `(15.3(<10.0~21.4)` 여는 괄호 중복 → 보정 파일에서만 `15.3(<10.0~21.4)` 로 보정.
- 표 2.19 `-*`(동위원소비 산출 불가 각주)는 값에 남김.
- 표 2.3 의 2025-03-09 채취분이 원문에서도 2월 묶음에 속함.
- 표 3.2 인치 기호가 글꼴 매핑 차이로 `3 ̋ × 3 ̋` 처럼 읽힘.
- 부록1 표5 의 [계속] 쪽 머리글 "해역" ↔ "해역 (정점수)".

## 재생성 방법

```
pip install -e .[dev]
python scripts/extract_marine_radioactivity_report.py
```

`data/processed/` 에 `2025_해양환경방사능조사_vol21_표.xlsx`, `…_표_분리.xlsx`, `…_표_분리_보정.xlsx` 가 생긴다. `--no-split` 으로 분리·보정 파일 생략, `--all` 로 제외 표까지 포함.
